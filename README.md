# middleware-app-practice

## 概要

COACHTECH 教材 Tutorial 10-2-4「ミドルウェア ハンズオン演習」で作成した成果物です。ミドルウェアを使用して管理者と一般ユーザーを区別するページを作成しました。

## 使用技術

- PHP 8.5.12
- Laravel 13.40.0
- カスタムミドルウェア（CheckAdmin）
- Laravel Fortify（認証）

## 学んだこと

- ミドルウェアの役割
- ミドルウェアの実装方法

## 動作確認

ブラウザから、
<http://localhost/login>
にアクセスして、
「管理者ページにアクセス」のボタンから、
<http://localhost/admin>
にアクセスして確認しました。

- 一般ユーザー：「403 | 管理者権限が必要です」と表示される
- 管理者：管理者ページが表示される
